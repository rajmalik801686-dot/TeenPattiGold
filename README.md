# TeenPattiGold (Android)

Native Kotlin & Jetpack Compose Android implementation of **Teen Patti Gold** (3-Card Indian Poker) using Material Design 3, Jetpack Navigation Compose, and DataStore persistence.

## Features
- **Four Authentic Variations:** Classic, Muflis (Lowball), AK47 (A, K, 4, 7 wild), and Joker (random wild rank per round).
- **Complete Teen Patti Rules:** Blind vs. Seen betting multipliers, 1x/2x Chaal raises, Sideshow requests (with Accept/Decline), Showdown, and Pot Limits.
- **Four Table Stake Tiers:** Bronze Lounge, Emerald Club, Royal Gold, and Maharaja VIP.
- **Smart AI Opponents:** 5-player oval emerald felt table with 4 distinct AI personas.
- **Virtual Bankroll & Daily Bonus:** Persistent virtual chip bankroll, career stats, daily bonus claims, and emergency free chip refills (entertainment only — virtual chips only).
